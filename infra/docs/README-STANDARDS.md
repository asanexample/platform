# README Documentation Standards

Standards for README files in infrastructure modules and Terragrunt configurations.

## Module READMEs

Each module README has two parts: **hand-written narrative** and **auto-generated reference**.

### Structure

1. **Title** — `# Module Name` followed by a one-line description
2. **Usage** — Single HCL block showing the common configuration with `create = true`
3. **Examples** — "Disabled" example (`create = false`), plus any meaningfully different configurations
4. **Cross-Cloud Interface** — (networking modules only) Table of shared output names
5. **`<!-- BEGIN_TF_DOCS -->` / `<!-- END_TF_DOCS -->`** — Auto-generated by `terraform-docs`; contains Inputs, Outputs, and Resources tables
6. **Dependencies** — Other modules this module depends on
7. **Notes** — Non-obvious gotchas, security considerations, cloud-specific constraints only

### What NOT to include

- **Overview/Features sections** — The title line covers this
- **Requirements/Providers tables** — Generated by the root Terragrunt config, not module-specific
- **License section** — Covered by the root LICENSE file
- **Validation Rules section** — Visible in `variables.tf`; auto-documented in Inputs table
- **Hand-written Input/Output tables** — `terraform-docs` generates these; hand-written tables drift

### terraform-docs

Input, output, and resource tables are auto-generated by [terraform-docs](https://terraform-docs.io/). Configuration lives in `.terraform-docs.yml` at the repo root.

To regenerate docs for a single module:

```bash
terraform-docs markdown table infra/modules/aws/networking
```

To regenerate all modules:

```bash
find infra/modules -name "*.tf" -exec dirname {} \; | sort -u | xargs -I{} terraform-docs markdown table {}
```

The `<!-- BEGIN_TF_DOCS -->` / `<!-- END_TF_DOCS -->` markers define the injection zone. Everything outside the markers is preserved.

## Terragrunt Configuration READMEs

Each Terragrunt configuration directory should include a README.md with:

1. **Title** — Resource name, region, and environment
2. **Overview** — One-line description of what the configuration deploys
3. **Dependencies** — List of dependency modules with descriptions
4. **Key Configuration** — Important settings and their values
5. **Usage** — `terragrunt plan` / `terragrunt apply` instructions

## Review Checklist

- [ ] Title + one-line description are accurate
- [ ] Usage example compiles and shows the common case
- [ ] `create = true` shown in Usage; `create = false` shown in Examples (for resource-creating modules)
- [ ] `<!-- BEGIN_TF_DOCS -->` markers present
- [ ] `terraform-docs` has been run after any variable/output changes
- [ ] Dependencies list is current
- [ ] Notes contain only non-obvious information (no padding)
